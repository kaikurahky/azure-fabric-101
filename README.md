# Microsoft Fabric を触ってみる：小さな売上分析を完成させるハンズオン

公式情報確認日：2026年10月22日  
対象：Fabric・Azure・SQL・Power BI が初めての方  
形式：ブラウザー操作中心。コピーして実行できる SQL と DAX、練習用 CSV 付き

## GitHub からの使い方

このリポジトリは、GitHub 上でそのまま読み進められる Markdown 形式の教材です。以下の目次から準備編・実習編へ移動できます。

- **教材を読む**：この README から各章のリンクを開いてください。
- **練習用ファイルをまとめて取得する**：リポジトリ上部の「Code」→「Download ZIP」でダウンロードし、展開してください。Git を使う方は clone でも構いません。
- **CSV を個別に取得する**：下の「同梱ファイル」から CSV を開き、GitHub の「Download raw file」を使用してください。Web ページ自体を保存するのではなく、CSV の内容を取得します。
- **SQL・DAX を使う**：対応するファイルを開き、実習の説明に従ってクエリや式を1つずつコピーしてください。

教材を読むためのビルド、パッケージのインストール、GitHub Pages の設定は不要です。Fabric の実習には別途、準備編で説明するアカウント・容量・権限が必要です。

## 最初にお読みください

**Fabric のトライアルが終了している場合は、まず [準備編](./00-setup.md) の「0-1」を確認してください。**

トライアル終了後、非 Power BI アイテムを救済するための再割り当て期間は、公式ドキュメントでは **7日**です。期限を過ぎたデータが必ず復元できるとは限りません。通常のワークスペース削除に対する保持期間とは別の話です。

この教材は、新しい無料トライアルを開始する方法ではありません。**既存ワークスペースを、Azure で購入する有料の Fabric 容量へ再割り当てする**方法を説明します。

教材の作成にあたり、お使いの Azure・Fabric へのアクセスやリソースの作成、課金を伴う操作は行っていません。

## この教材で完成させるもの

架空の小さなお店の売上データから、次の問いに答える分析を作ります。

- 合計売上はいくらか。
- どの商品が一番売れたか。
- 月ごとの売上はどう変わったか。
- East と West のどちらが売れているか。
- 新しい売上を追加すると、集計とレポートはどう変わるか。

```text
手元の CSV
    ↓ アップロード
Lakehouse の Files（原本）
    ↓ Load to tables
Lakehouse の Tables（Delta テーブル）
    ├─ SQL 分析エンドポイント → SQL による検算
    └─ セマンティックモデル → Power BI レポート
```

### Power BI Pro / PPU がない場合

**準備編と実習1～4、実習8の SQL 検算までは学習できます。**

この教材で使う共同作業用ワークスペースでは、Power BI レポートを作成・保存するユーザーに Pro または PPU が必要です。F2 を購入しても個人ライセンスは付いてきません。レポート編に進む前に管理者に確認してください。

CSV は UTF-8、カンマ区切り、1行目が列名です。通貨は日本円、税・値引き・返品は考えません。個人情報や実データは含みません。

教材の期待値は同梱 CSV からローカルで検算しています。実際の Fabric テナントでの SQL／DAX 実行や画面操作は未検証です。各実習の合格ラインで、ご自身の環境での動作を確認してください。

VS Code 上で教材を開いている場合は Markdown プレビューで読むと見やすくなります。Fabric のアップロード画面には **ブラウザーを使っている PC のファイル**を指定します。リモート環境でこの教材を開いている場合は、先に CSV を PC にダウンロードしてください。

## 進め方

1. 既存データ救済と、新規学習用アイテムの作成を分ける。
2. 操作する前に「いま、どのワークスペースを開いているか」を見る。
3. 各実習の「合格ライン」を確認してから次へ進む。
4. エラー時は、操作名・時刻・メッセージを記録する。何度も追記しない。
5. 学習終了時は、対象容量を他の人が使っていないことを確認して一時停止する。
